# spec — 설정의 기능 목록 탭

## 목표

설정 화면을 `[설정] [기능]` 두 탭으로 나누고, 기능 탭에 이 플러그인의 기능 이름과 하는 일을
ToolGroup 별로 보여준다.

## 범위

1. `src/features.ts` (obsidian 비의존) — ToolGroup·기능 목록을 **한 곳에** 둔다.
   - 기능은 두 종류: `command`(커맨드) / `included`(다른 커맨드에 딸려 함께 도는 동작).
   - `commandName(id)` — 커맨드 이름을 여기서 꺼낸다.
2. `main.ts` — 커맨드 이름을 `commandName()` 으로 등록한다. 기능 탭과 명령 팔레트 이름이
   같은 출처를 읽어 어긋날 수 없게.
3. `settings.ts` — 설정 페이지 안 탭 바. 기존 설정 항목은 `설정` 탭으로, 목록은 `기능` 탭.
   - 스타일 파일을 만들지 않는다. 활성 탭은 Obsidian 기본 `mod-cta` 버튼으로 구분한다.
   - 우리 설정 컨테이너 안에서만 그린다. 감시자·타이머 없음.
   - `기능` 탭의 이월 설명에는 현재 설정된 섹션 이름을 보여준다.

## 범위 밖

- 단축키 표시 (Obsidian 비공개 API `hotkeyManager` 가 필요하다)
- 기능 탭에서 커맨드 실행 버튼
