# context — 설정의 기능 목록 탭

## 원 요청 (2026-09-29)

> 기능 이름이 머야? 설정 ui에서 기능 이름 보여주는 화면도 하나 만들어줘. 이건 탭으로 분리해줘.

직전에 만든 "내일 이어서 할 것 이월" 은 별도 커맨드 없이 `전일 진행 업무 로드` 안에서 돈다.
그래서 이름이 명령 팔레트에도 설정에도 드러나지 않았다. 이게 질문의 출발점으로 본다.

## 결정

| 결정 | 이유 | 상태 |
|---|---|---|
| "탭" = 설정 페이지 **안의** 탭 | `addSettingTab` 을 두 번 부르면 사이드바에 플러그인 이름이 두 번 뜬다 | [가정] |
| 목록 정본은 `features.ts` 하나 | 커맨드 등록과 화면이 따로 이름을 가지면 한쪽만 고치는 날 어긋난다 | 추천 |
| 이월은 `included` 로, 딸린 커맨드를 가리킨다 | 커맨드가 아니지만 기능이다. 따로 커맨드로 만들지 않기로 한 결정(carry-over D4)은 유지 | [확정] |
| 스타일 파일 없이 `mod-cta` | 파일 하나 늘리는 것보다 기본 클래스로 충분하다 | 추천 |
